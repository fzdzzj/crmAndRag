# 规范增量：document-chunking

## ADDED Requirements

### Requirement: 切分策略可配且保锚点
系统 SHALL 支持语义切分与固定切分两种策略并经动态配置切换；任何策略下切片的页码/行号锚点 MUST 保留，固定策略 MUST 与既有切分行为等价。

#### Scenario: 语义切分
- **WHEN** 切分策略为 semantic 且文档含段落/标题边界
- **THEN** 切点落在语义边界上，段长不超过配置上限，跨上限的段按上限二次切分

#### Scenario: 锚点保留
- **WHEN** PDF/Excel 经 semantic 策略切分
- **THEN** 每个切片携带正确的 pageNo/rowIndex，页级来源引用（D15）不受影响

#### Scenario: 固定策略回退
- **WHEN** 切分策略为 fixed
- **THEN** 切分结果与升级前实现一致

### Requirement: 块头注入与展示分离
系统 SHALL 在嵌入文本前注入文档级上下文头（文件名、类目、页码）；存储与引用展示的块文本 MUST 保持原文。

#### Scenario: 嵌入带上下文头
- **WHEN** 切片被向量化
- **THEN** 嵌入输入为"上下文头 + 块文本"

#### Scenario: 展示不受污染
- **WHEN** 切片文本被存储或进入来源引用
- **THEN** 内容为原文，不含上下文头前缀

### Requirement: 双粒度索引
系统 SHALL 支持检索单元（小块）与生成单元（父块）分离：小块被嵌入与检索，命中后父块进入上下文；来源引用 MUST 仍指向命中小块。

#### Scenario: 小块检索父块生成
- **WHEN** 命中小块且父块展开开启
- **THEN** 上下文包含父块完整内容，引用与跳页锚点指向命中小块

#### Scenario: 展开可关闭
- **WHEN** 父块展开关闭
- **THEN** 上下文行为回到邻居增强模式

### Requirement: 幂等重建入库
系统 SHALL 提供按文档标识的重建入库：清理旧向量与切片、重新切分与嵌入、重写存储；重复执行 MUST 产出一致的切片集合，失败 MUST 清理半量不留脏数据。

#### Scenario: 重建幂等
- **WHEN** 同一文档连续执行两次重建
- **THEN** 两次切片集合（文本、锚点、父子关系）一致

#### Scenario: 失败清理
- **WHEN** 重建在嵌入阶段失败
- **THEN** 该文档的向量与切片被清理，文档状态标记失败且可重试，不产生半量检索结果

#### Scenario: 重建需授权与审计
- **WHEN** 触发重建
- **THEN** 仅知识库写授权用户可触发，且审计记录产生
