# 规范增量：rag-context

## ADDED Requirements

### Requirement: 邻居上下文增强
系统 SHALL 为每个命中切片提供紧邻切片的上下文拼装（前置/后置），邻居 MUST 仅进入上下文而不进入来源引用。

#### Scenario: 邻居拼装
- **WHEN** 命中切片存在同文档相邻切片且邻居开关开启
- **THEN** 上下文中该切片带前置/后置邻居内容，来源引用仍仅指向命中切片

#### Scenario: 不跨文档
- **WHEN** 命中切片为文档首/末切片或相邻切片属于其他文档
- **THEN** 不拼接不存在或跨文档的邻居

#### Scenario: 开关回退
- **WHEN** 邻居开关关闭
- **THEN** 上下文构造行为与升级前一致

### Requirement: 上下文压缩与 token 预算
系统 SHALL 在上下文超过 token 预算时执行压缩，压缩器 MUST 提供确定性规则实现为默认与回退，LLM 压缩可选启用且失败回退规则链；压缩所耗 token MUST 纳入平台计量。

#### Scenario: 超预算压缩
- **WHEN** 拼装后的上下文超过动态配置的 token 预算
- **THEN** 压缩后上下文不超过预算，且承重要素（数字、锚点词、首末句）优先保留

#### Scenario: 未超预算不压缩
- **WHEN** 上下文在预算内
- **THEN** 原文逐字保留，不做任何改写

#### Scenario: LLM 压缩回退
- **WHEN** LLM 压缩模式启用且调用失败、超时或返回空
- **THEN** 回退规则压缩完成本轮组装，不向调用方抛错
- **AND** 压缩调用的 token 消耗被计量

### Requirement: 引用编号完整性
上下文增强与压缩 MUST 保持上下文中引用编号与来源列表的一一对应，不得因邻居或压缩破坏映射。

#### Scenario: 编号映射不变
- **WHEN** 上下文经邻居拼装与压缩后进入生成
- **THEN** 上下文中的引用编号能唯一定位来源列表中的对应条目（citationPrecision 判定依据不受影响）

### Requirement: 消费侧参数化
助手侧知识库检索的 topK MUST 从动态配置解析，不再硬编码；配置缺失时回退默认值。

#### Scenario: 配置生效
- **WHEN** 动态配置设定检索 topK
- **THEN** 助手知识库检索按配置值取数

#### Scenario: 缺省回退
- **WHEN** 未设定配置
- **THEN** topK 回退默认值（4），行为与升级前一致
