# 规范增量：rag-query

## ADDED Requirements

### Requirement: 多查询生成与融合
系统 SHALL 支持将单一检索查询扩展为原始查询加 N 个变体（补全、拆解、视角变换），多路召回结果 MUST 按排名融合为单一候选集；该能力 MUST 默认关闭且关闭时行为与升级前一致。

#### Scenario: 多查询融合
- **WHEN** 多查询启用且变体生成成功
- **THEN** 各路召回按 RRF 融合后进入统一重排，检索结果来自融合候选集

#### Scenario: 部分降级
- **WHEN** 部分变体路失败或超时
- **THEN** 以已完成路融合继续，不向调用方抛错

#### Scenario: 全部失败回退
- **WHEN** 变体生成全部失败
- **THEN** 回退单查询检索，行为与升级前一致

### Requirement: HyDE 可选模式
系统 SHALL 支持假设性文档嵌入检索：由查询生成假设答案并以其向量参与检索；假设答案 MUST 仅用于检索，不得进入生成上下文或来源引用；该模式 MUST 默认关闭。

#### Scenario: 假设答案隔离
- **WHEN** HyDE 启用并生成假设答案
- **THEN** 假设答案文本不出现在生成上下文与引用中，仅其向量参与召回

#### Scenario: 失败回退
- **WHEN** 假设答案生成或嵌入失败
- **THEN** 回退原查询向量检索，不向调用方抛错

### Requirement: 衍生问题文档增强
系统 SHALL 支持在入库旁路为切片生成反向衍生问题并向量化关联原切片；衍生问题生成 MUST 不阻塞入库主链、失败时切片退化为普通块；命中衍生问题时来源引用 MUST 指向原切片。

#### Scenario: 衍生问题命中
- **WHEN** 查询与某衍生问题向量匹配
- **THEN** 关联原切片进入候选，引用与锚点指向原切片

#### Scenario: 旁路不阻塞
- **WHEN** 衍生问题生成失败或超时
- **THEN** 文档入库正常完成，该切片无衍生向量，不产生失败状态

#### Scenario: 计量
- **WHEN** 衍生问题生成与嵌入执行
- **THEN** 其 token 消耗被计量

### Requirement: 成本敏感增强的默认关闭
本能力域所有查询侧增强（多查询、HyDE、衍生问题）MUST 默认关闭，启用 MUST 经动态配置显式开启；每项增强 MUST 有失败回退到升级前行为的路径。

#### Scenario: 默认关闭
- **WHEN** 未显式启用任何查询侧增强
- **THEN** 检索与入库行为与前置变更完成态一致
