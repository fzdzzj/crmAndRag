# 提案 · OBS-1 机械核对脚本修复 (fix-review-mechanical-check-true)

> 档位：C 档（工程小卡，纯 scripts 修复）
> 来源：`work/_paa-candidates-pool.md` §7 工程脚本缺陷修复（L124 / L183）
> 基线：master@1c314b7（排队卡：待前两卡闭环后派发）

## 1. 背景与目标

`scripts/tests/review-mechanical-check.sh` 中存在 `|| true`，导致核对失败被吞、基线漂移无法精准报警
（§110 OBS-1）。本卡修复：

1. 移除脚本内的 `|| true` 吞错模式，让核对失败真实反映在退出码；
2. 全脚本审读一遍，同类吞错模式（如 `|| echo` 后未传递退出码）一并修复；
3. 自测：构造一个应失败场景验证退出码非 0，恢复正常场景退出码 0。

## 2. 非目标

不改脚本核对逻辑本身（只修错误传递）；不将其升格为 CI 门禁（维持非门禁定位，AGENTS.md 口径）。

## 3. 验收

- 应失败场景实测退出码非 0、正常场景退出码 0（两向验证留证）；Java 侧零改动（基线持平）。
