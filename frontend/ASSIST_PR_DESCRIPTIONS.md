# 协助功能 PR 拆分说明

## PR-1：协助页面与基础入口

### 背景与目标

此前系统缺少完整的协助业务入口，业务活动、联络任务和订单推进无法统一发起协助申请，协助人也没有独立的待办页面。

### 主要改动

1. 新增协助人选择与多选组件；
2. 业务活动、联络任务、订单推进接入申请协助入口；
3. 新增“待我协助”页面；
4. 增加协助记录查询与状态展示；
5. 增加协助基础接口封装；
6. 增加业务详情中的协助人入口。

### 测试验证

- `pnpm type-check:check`
- `pnpm lint:check`

### 注意事项

- 后续协助详情、附件、快照 PR 基于本 PR；
- 分支：`pr/assist-01-page`。

---

## PR-2：协助接口契约与 CI 校验

### 背景与目标

协助功能新增了多组接口，前端 OpenAPI 契约与后端接口需要保持一致，并纳入自动化校验，避免接口变更导致前端类型漂移。

### 主要改动

1. 更新协助相关 OpenAPI 契约；
2. 增加 OpenAPI 同步脚本；
3. 增加 OpenAPI 契约校验脚本；
4. 增加 CI 契约检查；
5. 对齐前端依赖和检查命令。

### 测试验证

- OpenAPI contract check；
- `pnpm type-check:check`；
- `pnpm lint:check`。

### 注意事项

- 基于 PR-1；
- 分支：`pr/assist-02-contract-ci`；
- 建议先合并本 PR，再合并后续协助业务 PR。

## PR-3：协助生命周期与处理流程

### 背景与目标

协助申请创建后缺少完整的处理闭环，无法支持待协助、已协助、已驳回、已拒绝等状态，也无法维护协作目的、要求和处理结果。

### 主要改动

1. 新增协助申请详情页面；
2. 支持待协助、已协助、已驳回、已拒绝状态；
3. 支持协助处理、驳回、拒绝；
4. 支持重新申请和追加协助；
5. 增加协作目的、协作要求、协助内容；
6. 增加协助交付物附件上传；
7. 完善协助状态标签和页面交互。

### 测试验证

- `pnpm type-check:check`；
- `pnpm lint:check`。

### 注意事项

- 基于 PR-2；
- 分支：`pr/assist-03-lifecycle-ui`。

---

## PR-4：协助关联业务导航

### 背景与目标

协助详情只能查看协助本身，无法快速定位关联的公司、联系人、业务活动和联络任务，影响协助处理效率。

### 主要改动

1. 新增协助关联记录展示组件；
2. 支持打开关联公司和联系人；
3. 支持打开关联业务活动和联络任务；
4. 普通业务详情接入协助人信息；
5. 完善协助场景下的关联数据展示。

### 测试验证

- `pnpm type-check:check`；
- `pnpm lint:check`。

### 注意事项

- 基于 PR-3；
- 分支：`pr/assist-04-related-navigation`；
- 关联详情接口依赖后端协助专用读取接口。

---

## PR-5：协助详情快照

### 背景与目标

协助完成后，原始业务数据可能继续变化。终态协助详情需要保留处理时的业务内容，避免历史详情发生漂移。

### 主要改动

1. 新增协助快照解析工具；
2. 新增关联业务快照展示组件；
3. 终态详情使用冻结快照；
4. 终态不再回查实时业务详情；
5. 快照中支持展示业务字段和附件；
6. 增加快照解析单元测试。

### 测试验证

- `pnpm test -- tests/assistSnapshot.test.ts`；
- `pnpm type-check:check`；
- `pnpm lint:check`。

### 注意事项

- 基于 PR-4；
- 分支：`pr/assist-05-detail-snapshot`；
- 终态数据依赖后端生成并保存协助快照。

---

## PR-6：协助详情与业务附件

### 背景与目标

协助详情打开业务活动或联络任务时，原有页面无法展示完整业务字段和对应附件；同时需要区分业务附件与协助交付物附件。

### 主要改动

1. 新增协助关联业务详情弹窗；
2. 使用协助专用业务活动详情接口；
3. 使用协助专用联络任务详情接口；
4. 使用协助专用业务附件接口；
5. 待协助阶段展示实时业务附件；
6. 终态阶段展示快照业务附件；
7. 区分业务附件和协助交付物；
8. 支持待协助阶段上传业务来源附件。

### 测试验证

- `pnpm type-check:check`；
- `pnpm lint:check`；
- 快照测试。

### 注意事项

- 基于 PR-5；
- 分支：`pr/assist-06-delivery-attachments`；
- 后端需包含协助专用详情和附件接口；
- 普通业务详情中的协助人弹窗不展示业务附件。

## PR-7：修复关联业务附件加载

### 背景与目标

待协助详情打开业务活动或联络任务时，详情请求可能发出，但附件请求因状态判断或详情请求异常被阻断，导致弹窗没有业务附件。

### 主要改动

1. 修正待协助状态判断；
2. 只有明确的非 0 状态才视为终态；
3. 待协助状态继续请求业务活动/联络任务专用附件接口；
4. 详情请求和附件请求并行执行；
5. 详情接口异常时不阻断附件请求；
6. 普通业务详情中的协助人弹窗继续隐藏业务附件；
7. 终态仍只读取快照附件。

### 测试验证

- `pnpm type-check:check`；
- `pnpm lint:check`。

### 注意事项

- 基于 PR-6；
- 分支：`pr/assist-07-attachment-fixes`；
- 这是针对协助详情附件加载问题的修复 PR。

## 后端 PR：协助详情与附件访问权限

### 背景与目标

前端协助详情和附件展示需要绕过普通业务数据权限切面，但仍必须校验协助记录、关联业务记录和生命周期状态，避免越权读取。

### 主要改动

1. 协助实时业务详情使用协助专用权限校验；
2. 协助业务活动和联络任务附件使用协助范围读取；
3. 终态快照附件使用协助快照校验；
4. 保留 `assistId`、来源记录和生命周期校验；
5. 增加协助详情与附件权限回归测试。

### 测试验证

