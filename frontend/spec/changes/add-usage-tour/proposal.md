# 使用教程与新手引导

## Why

新用户登录后直接落在客户列表页，没有任何使用引导；系统中大量功能存在多种用法入口（例如"协助"既可以在创建业务活动、联络任务、推进销售阶段时随表单申请，也可以在"待我协助"页处理、"我的申请"页重新申请或追加协助，还可以在业务详情中查看协助人），仅靠口头传达学习成本高；新功能（协助、部门管理等）合入后也缺少向存量用户展示的渠道。

本次变更提供一套站点内的"使用教程"能力：教程抽屉（快速上手/基础教程/进阶教程）+ 基于真实页面的聚光灯高亮分步引导，教程内容按 main 现有功能的真实入口编写。

## What Changes

- 新增全局"使用教程"入口（顶栏帮助按钮），打开教程抽屉；抽屉含"快速上手/基础教程/进阶教程"三个分类页签，教程条目展示标题、简介、步骤数与"开始"按钮。
- 新增配置化引导引擎：教程以常量配置声明（目标路由 + data-tour 锚点 + 中文文案），开始引导后按步骤自动跳转页面、等待锚点渲染、聚光灯高亮并弹出步骤气泡，支持上一步/下一步/结束。
- 新增页面锚点：在客户、联系人、销售、合同、审批、联络任务、业务活动、财务、组织、权限、协助等页面的关键按钮/区块上添加 data-tour 属性（仅加属性，不改交互）。
- 新增首次登录自动弹出：按用户 ID 记录 localStorage 标记，每个用户只自动弹出一次教程抽屉。
- 新增教程完成记录：完成全部可用步骤后按用户 + 教程维度持久化"已完成"标识。
- 权限差异降级：无权限导致锚点元素不渲染时自动跳过该步骤，结束前汇总提示。
- 引入 driver.js（约 20KB、零依赖）实现遮罩挖孔高亮与气泡。

## Impact

- 影响：新增 `src/constants/tour/`（教程配置）、`src/hooks/useTutorial.ts`（引导引擎）、`src/utils/tutorialStorage.ts`（本地标记）、`src/components/tutorial/TutorialDrawer.vue`（教程抽屉）；修改 Header（入口按钮）、`(dashboard).page.vue`（挂载抽屉与首次弹出）及约 16 个页面/组件（data-tour 锚点）。
- API：无任何后端接口变更；教程内容为前端常量，更新文案随前端发版。
- 规范：新增 usage-tour 能力规范；无既有规范修改。
- 用户：所有登录用户可见"使用教程"入口；首次登录自动弹出一次。
