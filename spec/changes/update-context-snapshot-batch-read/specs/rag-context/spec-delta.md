# 规范差异：rag-context 快照批读与等价验收

此增量在既有邻居增强、父块展开、压缩与来源编号规范之上**新增内部读取约束**，不改变既有用户可见契约。旧行为来源：`openspec/changes/archive/add-context-compression-and-enrichment/specs/rag-context/spec.md` 与 `openspec/changes/archive/upgrade-semantic-chunking-and-index/specs/document-chunking/spec.md`。下列规范不涵盖需另案修复的缺失 `chunkIndex` 拆箱缺陷。

## ADDED Requirements

### Requirement: 有界批读且上下文语义不变
WHEN 检索结果包含多个可回查的命中切片且启用父块或邻居增强,
系统 SHALL 按有界批次读取相关子块、父块和同文档邻居，并按原候选顺序拼装与旧路径逐字等价的上下文；邻居 SHALL 只进入上下文而不进入来源引用。系统 MUST NOT 改变授权 KB 范围、检索命中集合或调用模型/向量库的次数。

#### Scenario: 五命中无父块
GIVEN 相同授权的四库查询返回五个具有数字 chunkId 和有效 chunkIndex 的命中
AND 快照中子块均无父块且邻居增强开启
WHEN 组装上下文
THEN 输出文字、编号及来源锚点与原逐命中实现一致
AND 成功路径快照查询次数不超过三次，不再逐命中查询子块和邻居

#### Scenario: 父块与邻居混合
GIVEN 同一批命中中既有带父块的子块，也有无父块或父块缺行的子块
WHEN 父块展开和邻居增强同时开启
THEN 有父块的命中只用其父块全文作生成上下文，其余命中按旧规则拼接邻居
AND 每个来源仍指向原命中小块，候选排序及 `[n]` 编号不变

#### Scenario: 邻居取舍与隔离
GIVEN 不同文档的候选及同索引多个邻居行，且存在首末块或跨页邻居
WHEN 按批次读取邻居
THEN 每个命中仅使用同文档、CHILD 角色、目标 chunkIndex 的有效快照行
AND 同页优先、同页主键小者优先的取舍与原路径一致，绝不把跨文档行拼入上下文

#### Scenario: 关闭增强或空列表
GIVEN 没有命中，或父块展开与邻居增强均被关闭
WHEN 构建上下文
THEN 保持既有空结果或纯编号文本行为
AND 不为批读额外访问快照表

### Requirement: 批读失败时保持最佳努力降级
IF 任一批次快照读取抛出异常,
系统 SHALL 在读取层告警并保留其他成功批次；受影响命中可有界逐条回查或按既有无父块/无邻居语义降级，但 MUST NOT 在持续故障时按候选数无限制重试放大数据库压力。系统 MUST NOT 扩大检索范围或丢弃已成功命中的来源，也不得为批读开启覆盖模型或向量库外呼的长事务。

#### Scenario: 批读异常
GIVEN 多个命中分属两个批次，第一批成功而第二批读快照抛异常
WHEN 批查抛异常
THEN 第一批保持已有上下文，第二批在有界回查后拼装或按原有无父块/无邻居语义降级
AND 所有命中的来源、顺序与引用编号保持原样，持续故障下快照查询次数受限

#### Scenario: 大候选集合
GIVEN 候选数量超过一个批次的安全参数上限
WHEN 查询父子块与邻居
THEN 将查询拆为有限大小的批次
AND 不生成无界 IN 参数或省略任何候选的原有上下文

### Requirement: 同负载前后测量且无越界结论
WHEN 判断批读是否值得合入,
系统 SHALL 在实施前取得现行生产读取实现的新鲜基线，实施后以同一授权、查询、命中、种子、假模型和本机存储执行条件复测，记录每请求快照 SQL、上下文与端到端 P50/P95、吞吐、失败及资源；至少两独立执行，并将 c8 首窗与后续窗口分开报告。系统 MUST NOT 以 SQL 次数下降单独宣称性能收益或外推生产真实模型 RTT。

#### Scenario: 可比的前后测量
GIVEN 当前未修改代码的旧路径和改动后的批读路径都完成显式 opt-in 安全预检
WHEN 两者用四库、topK 5、五命中固定负载分别测量
THEN 按相同轮次记录调用形状、分位、吞吐、失败与资源，且输出语义相同
AND 旧合成/真存储基准与诊断账本的精确调用断言按新形状更新而不删减，披露 JaCoCo、采样开销、c8 首窗波动及模型桩不代表真实外呼的限制

#### Scenario: 负载不可比或无稳定改善
GIVEN 两边的种子、有效配置、样本或命中不同，或两次执行的延迟/吞吐结果不能支持同向改善
WHEN 汇总验收结论
THEN 将结果标为不可比或假设未获支持，记录反例并停止优化实现的交付
AND 不调整 JVM、连接池、线程池、向量并行或生产费用开关来追求指标

#### Scenario: 环境不具备安全测量条件
GIVEN Docker、本地镜像或固定假模型条件不可用
WHEN 尝试运行显式度量
THEN 在付费外呼和容器下载前停止，报告未测而不是以旧 shim 或合成数字替代
AND 默认单测及 merge-gate 不自动运行该显式度量入口
