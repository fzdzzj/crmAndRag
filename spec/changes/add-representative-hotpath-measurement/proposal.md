# 提案：本机隔离环境请求热路径度量（不调用付费模型）

## Why

`docs/request-hotpath-baseline.md` 已固定检索与摄取的调用形状，但其远程/SQL 时间来自假端口注入，查询改写与授权 SQL 也未完整计时。它只能给出合成参数下的条件结论，不能选定生产瓶颈。下一步需要在不自动付费、也不改变生产行为的前提下，把同一负载接到真实的**本机隔离 MySQL/Qdrant**，同时保留明确的模型假端口，测出本机存储、应用侧分段、吞吐与资源占用。该结果仍不是生产环境 RTT；真实模型段需另行授权。

## What Changes

- 在 `src/test` 增加**显式 opt-in、默认测试发现不到**的度量入口，例如 `RepresentativeHotpathBenchmark`（不以 `Test`、`Tests`、`IT`、`IntegrationTest` 结尾）。仅显式指定测试名且提供本案独立开关才可运行；开关检查在容器启动和装配之前执行。`mvn test`、`mvn verify`、`merge-gate.sh` 不自动运行它，不修改生产端点或默认配置。
- 隔离环境只使用预先存在的本地 Docker 镜像、一次性 MySQL/Qdrant 容器及固定种子。启动前检查 Docker/镜像；缺失时明确失败并列为“未测”，**不得自动拉取镜像、使用开发/生产数据库或报告成功**。沿用现有依赖；若证明需新增依赖，先停下单独审批。真实 MySQL 的 Flyway 结构、真实 SQL/索引与真实 Qdrant 客户端/过滤条件须经过生产实现；模型 `embed/chat/改写` 全部硬绑定确定性本地假实现，不能通过环境变量或仓库 `.env` 回退到 `ModelProviderImpl`，不读取真实密钥。
- 固定与上案可对照的工作量：检索 4 个已授权 KB、单路查询「客户合同续签流程」、topK=5，种子文本、命中规模、动态配置、召回路及授权用户记录下来；摄取同样 6600 字符、fixed 320/40、预期 24 子块。先验证实际行数、命中、调用次数、向量维度/metadata 与现有基线口径；形状不同就标记“不具可比性”，不能偷换负载。检索与摄取分开运行；摄取为每次写入使用隔离文件并在计时窗口之外复位数据，不能让累计数据量改变后续样本的输入状态。
- 在测试/度量装配侧记录每请求端到端墙钟、逐段调用次数与耗时：授权/JDBC SQL（包括授权查询）、查询改写假端口、嵌入假端口、Qdrant 检索/写入、稀疏检索、融合重排、上下文拼接及摄取的解析/写库。记录 SQL 语句数及按模板聚合的耗时、连接获取/等待（可取得时）；并发段单独记录队列/等待。计时器标记包含/独占和重叠关系，**不把各段墙钟简单相加后冒称 CPU，也不把“总耗时−外部耗时”冒称业务规则**。
- 同一组种子、配置、机器和提交下完成预热与多轮稳态采样；检索至少单并发和一个固定并发档，摄取独立设定固定并发档。每档记录样本数、窗口时长、成功/失败数、吞吐（成功请求/秒）、p50/p95/p99、CPU 进程用量、堆使用/峰值、GC 次数及暂停、线程数；能采到时另记锁等待/JFR、MySQL/Qdrant 容器资源。记录冷启动/预热与稳态的界线、JaCoCo/分析代理状态。无采样即明确标“未观测”，不以 0 填充。
- 新增 `docs/representative-hotpath-measurement.md` 记录可复现命令、机器/JDK/镜像摘要、固定负载与数据规模、计时窗口、原始汇总、分段覆盖率及剩余未知。仅当真实本机度量成功时填写数字；输出含密钥/用户文本的原始日志不提交。现有 `docs/request-hotpath-baseline.md` 的合成数字和测试断言不改。

## Impact

- **范围**：测试侧度量入口、测试装配与文档、这组三件套。允许复用既有生产类，但不修改 `src/main`、`pom.xml`、Flyway、前端、`ci.yml`、动态配置、基线阈值、线程池或 JVM 参数。
- **API/数据**：无 API 契约、生产数据或 schema 变更；一次性容器中写测试数据，不能连开发/生产实例。
- **开销/风险**：本机 Docker 占用 CPU/内存，计时/JaCoCo 会有观测开销；真实本机 Qdrant 网络 RTT 不等于模型供应商或生产跨机 RTT。单机低并发结果不得外推生产 P99、扩容能力或总体资源预算。
- **授权边界**：本案不设置 `RAG_BENCHMARK_REAL=1`、`RAG_VISION_PDF_REAL=1`，不执行任何真实模型、embedding、真向量付费试点或生产开关。需要测真实 Provider 时另交 owner 批准费用上限、样本量、密钥作用域及停止条件，不因本案 tasks 全勾而自动授权。

## 验收与决策边界

1. 默认 Maven/merge-gate 路径零外发、零本案容器启动；显式入口在镜像缺失、配置异常或真实 Provider 混入时 fail closed。实际执行前须核对本地 Docker 与镜像存在，不下载。
2. 数据集和调用形状可与旧基线逐项核对；若实际生产 SQL/授权/真实 payload 改变命中数，应保留差异证据而非改旧数字。分段计时与端到端在相同窗口，失败/超时单独列出。
3. 至少两轮相同负载可复跑；容量、并发、容器/主机资源与分位完整披露。大波动、不足样本、计时覆盖不足、不同来源时标或结果不一致均只报告“无法归因”，不调参补齐结论。
4. 仅可把**本机真实存储 + 本地模型桩**的最高占比列为候选调查项，且需注明模型远程 RTT 未知、生产瓶颈未定；下一张生产优化提案必须在相应真实/代表性环境同负载重测或取得 owner 授权后才能选类。不得因合成或本地模型桩结果自动实施逐库并行、批量 embedding、JVM/GC 调参。
