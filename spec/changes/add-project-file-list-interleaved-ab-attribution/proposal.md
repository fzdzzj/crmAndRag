# 提案：项目文件列表鉴权热路径交错 A/B 归因

> 2026-09-27 拟案；权威树起点 `master@b4db7b5` 仅为观察快照，实施前重查 HEAD、工作树、现行规格和本机环境。本案**只补端到端因果证据**，不重新引入已回退的 S1 旧角色复用，不改安全修复。

## Why

`docs/project-file-list-auth-hotpath-evaluation.md` §11.6.4 将 S2 的性能裁决下调为「有条件 / 未定」：修正“区间分离”公式后，被改路径 P50/P95/吞吐各只有 6/20 严格不重叠；同代码前测的安慰剂 P95 却有 8/20，且前测自身聚合 P50 已随时间下降 10.7%。这些是既有日志复算，并非本提案新测量。授权 SQL 调用形状变少与确定性交错安全回归成立，但不能代替端到端归因；也不能据噪声断言“没有收益”。

## What Changes

1. **冻结安全、输入与对照**：A 为优化前且角色改派回归为绿的 `31ba8c4`，B 为合入安全修复的 `d67c7e9`（若要改被测 ref，先写明原因并重新核差异）。只允许相同的测试侧度量入口/种子/测量代码在 A、B 两臂运行；核对基准源码哈希和 `src/main` 差异清单，拒绝 S1 `ce85e09` 做基线。记录镜像 digest、JDK、依赖、编译配置、资源与连接池；不可观测记 unknown。保留现行并发改派、撤权、分页及下载复核断言，任何安全反例失败即终止性能 GO。
2. **先注册实验设计再运行**：主负载沿用同一 opt-in 真 MySQL 基准的 10/50/100 页、权限分布、冷暖缓存、每 run 两轮及 c8 并发相；A、B 必须用独立、复位的数据容器，不接真实业务库。固定六个配对执行顺序 `AB, BA, AB, BA, AB, BA`，每臂六次独立 run；另以同一份 A 代码跑至少四次安慰剂校准并保留 run 顺序。整组调度不得按早期结果改序、选择有利窗口或只汇报成功行；单次失败记录并按事先固定的整对重跑/停止规则处理。执行前预先写定主指标（被改路径 20 单元的每 run 第 2 轮 P50 对数比的等权汇总，六个配对差为统计单位）、次指标 P95/吞吐/失败和未改路径阴性对照；第一轮和逐格数据仍完整展示，不把 20 单元当独立的 20 次实验。
3. **安全与费用守卫**：默认 surefire/merge-gate 不发现真库入口；只有显式 `PROJECT_FILE_LIST_HOTPATH_MEASURE=1` 才可启动。运行前 `docker info` 与本地 `mysql:8.0` 镜像实测，不自动下载；只用本地假身份/假令牌，无真实模型、真实附件、业务数据库、外发网络。资源采样不得在请求计时内同步阻塞；未采集的 CPU/GC/容器指标标 unknown，不能填 0。不要以本机旧 Docker 状态代替当轮预检。
4. **独立重算与条件裁决**：保存每 run 原始 stdout、条件行、run 身份/顺序、失败行、脚本及输出摘要；校验每 run 行数、`ok==requests`、页输出与 SQL 形状和安全探针，指标不能从四舍五入后的展示值假装得出更高精度。按配对差、先后顺序、A→A 安慰剂漂移与 ADMIN/FROZEN/LEAVER 阴性对照报告方向、量级及不确定性；置信区间若采用重采样，应以**配对 run**为抽样单位。预注册的保守 GO 判据：六对主指标差（B 相对 A 的等权对数 P50）必须全部小于 0，AB 与 BA 各自三对的中位差都小于 0，六对中位改善幅度大于四次 A 安慰剂按相邻 run 得到的最大绝对同代码对数 P50 漂移；P95 改善与吞吐不降各至少四对成立且两种顺序各自的中位值均不退化，失败为 0；未改路径若同样出现可比幅度的改善则不恢复 GO。样本有限，配对/安慰剂和阴性对照都不足以单独作因果证明；不满足即记未定或 no-go 并解释。满足上述条件也只能将 S2 **本机**性能裁决提升为有条件 GO，不能宣称生产收益。不能靠 SQL 减次、严格不重叠计数或挑选页大小单独恢复 GO；不宣称生产收益。
5. **有限交付**：允许新增/最小改动 `src/test` 中的测试侧度量/解析守卫、独立报告、本案三件套，必要时为历史报告增一条指向新报告的索引。不得更改 `src/main`、权限矩阵、迁移、依赖、CI/基线阈值、JVM/池参数；不回写历史原始表。环境不可用或强噪声时交付可复现设计与「未测/未定」，不得伪造通过；是否合并按真实门禁、仓库流程和无夹带文件裁决。

## Impact

- **规范**：新增 `specs/project-file-list/spec-delta.md` 的测量与裁决要求；不放宽原案 `update-project-file-list-auth-hotpath` 的权限/分页/端到端验收条款。
- **代码与报告**：只涉及测试侧入口、原始数据解析、报告与提案；生产接口/API、数据结构、默认执行和费用开关不变。
- **风险**：真容器实验耗时较长；编译/容器启动及宿主时间漂移需单独记录。若 A 的历史测试入口不能与 B 字节同构编译，先停下披露不可比性，不替换成无权的 S1 或跳过安全反例。
