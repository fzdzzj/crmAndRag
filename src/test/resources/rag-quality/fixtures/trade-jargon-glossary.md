# 贸易金融业务术语说明

【GOLD:jargon-factoring】应收账款保理属于企业流动资金管理工具：客户把尚未到期的应收账款按其面值折让转让给保理合作机构，机构提前向客户支付折让后的大部分款项，客户用这笔提前到账的资金补充经营周转，到期后由买方按原账期向机构兑付。申请前提是双方已签订购销框架协议且货物签收单与增值税发票齐备；合作机构按应收账款账龄与买方信用核定折让比例，账龄一年之内的转让价一般不低于票面金额的八成，账龄超过两年的原则上不再受理。客户提交申请后机构通常在一周内完成尽调与放款，合同期内客户不再承担该笔应收账款的催收义务，催收与账务处理均移交机构统一管理，双方月末对一次账，对账差异在下一结算周期内调整。
【GOLD:jargon-credit】授信敞口是指金融机构核准给客户的综合授信额度中，尚未被实际占用、仍可由客户随时申请支用的剩余可用部分。综合授信被批准后，客户真正提用的资金——包括已放贷款、已开立信用证占用与票据贴现占用——会逐笔从可用额度中扣减，尚未动用的余额即为授信敞口。客户申请新增融资前需先核对当前授信敞口是否充足，敞口见底的需先压缩存量用信，或向审批部门申请单笔临时增额，增额须重新走完整风控核资料流程。授信敞口的核算由客户经理按月与台账核对一次，遇重大用信集中投放时同步向合规复核，核算结果留存备查纳入后续授信复审参考，任何一笔挂账占用都会在下一月台账中如实反映。
【GOLD:jargon-discount】承兑汇票贴现是将未到期承兑汇票提前变现的短期融资方式：持票企业把手中尚未到期的银行承兑汇票背书转让给贴现机构，机构按票面金额扣除贴现日至到期日的利息后，把剩余款项一次性划入企业账户。贴现利率参考市场同期限资金价格每旬浮动，企业如遇流动性紧张可优先安排利率较低的短票贴现，贴现资料含原始票据、购销证明与贴现申请书三类。贴现完成后票据权利转让给机构，到期由机构向承兑人主张兑付，企业不再承担后续追索义务。企业财务部门应在贴现到期日前五个工作日复核票据状态并同步台账，贴现回笼资金按资金计划归集，归集结果在月末资金会议上汇总并进入下月预算安排。
