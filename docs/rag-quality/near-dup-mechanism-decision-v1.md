## 0. 一句话结论

**UNDECIDABLE-BY-DATA（C5 第 ③ 支：关节不可达、两侧可达）**：三机制全网格 550 点**没有任何一点**同时满足 C1（R_keep ≥ 0.90）与 C2（L ≤ 0.02），但两侧**各自可达**——
C2 侧最高保留 = **67.5%**（M1 `floor=0.98`，L=1.81%），C1 侧最低泄漏 = **3.26%**（M1 `floor=0.90`，R_keep=94.2%，即门槛 2% 的 1.63 倍）。
这不是"无机制可用"，而是**交换率已量出、但汇率没人能定**：把 `R_keep` 从基线 0.583 提到 0.90 的最小泄漏代价 = 3.261%（9/276）。
数值源自表 5/5 的 `verdict` 行、锚 `verdictReason` 与表 2/5 的 `floor=0.98` / `floor=0.90` 两行。

## 1. 基线（表 1/5）

| 指标 | 值 | 出处 |
| --- | --- | --- |
| 生效 floor | 0.9887 | 表 1/5 `floor=` |
| `R_keep` | 70/120 = **0.583333** | 表 1/5 `R_keep=` |
| `L` | 3/276 = **0.010870** | 表 1/5 `L=` |
| 逐 kind 保留数 | jpeg-q80=18 / scale-085=21 / scale-070=22 / crop-04=9 / crop-12=0 | 表 1/5 `逐kind=` |

基线逐 kind 保留数就是"41.7% 同源变体被当异图丢弃"的分解：**crop-12 全丢（0/24）**、crop-04 只留 9/24，
而 jpeg/scale 三档近满（18/21/22 每 kind 24 对）——走廊只接住"几乎不变"的变体，裁切类整体跌到 floor 以下。
C3 基线**不满足**：0 ≤ 9 ≤ 22，但 22 > 21（scale-070 22 对 > scale-085 21 对）；锚 `baseline.outcome.satisfiesC3=false`。

## 2. 三机制全网格（表 2/5、表 3/5、表 4/5）

三条机制的判据口径（写死在 `NearDuplicateMechanismAnalyzer` 常量里，跑前注册、跑后禁改）：

- **M1 floor 帕累托**：`threshold` 固定 0.9944，仅把 `floor` 从 0.90 扫到 0.9995（步长 0.0005，**200 点**）。保留 = `cosine >= floor`。
- **M2 dHash-64**：单阈值 `D`∈0..24（**25 点**），`dHash 距离 <= D` ⇒ 保留（近似带，不冒充同图）。
- **M3 混合**：`(D_low, D_high)` 全组合（`D_low ≤ D_high`，**325 点**）；`dHash<=D_low` ⇒ 同图；否则 `dHash<=D_high || cosine>=0.9887` ⇒ 近似带；否则丢弃。

关键行（完整网格见锚 JSON）：

| 机制/参数 | `R_keep` | `L` | 出处 |
| --- | --- | --- | --- |
| M1 `floor=0.9995` | 63/120 = 0.525 | 0/276 = 0 | 表 2/5 |
| M1 `floor=0.9935` | 64/120 = 0.533333 | 0/276 = 0 | 表 2/5 |
| M1 `floor=0.9887`（=基线） | 70/120 = 0.583333 | 3/276 = 0.010870 | 表 2/5 与表 1/5 互证 |
| M1 `floor=0.90` | 113/120 = 0.941667 | 9/276 = 0.032609 | 表 2/5 |
| M2 `D=0` | 23/120 = 0.191667 | 15/276 = 0.054348 | 表 3/5 |
| M2 `D=22` | 108/120 = 0.900000 | 62/276 = 0.224638 | 表 3/5 |
| M2 `D=24` | 112/120 = 0.933333 | 78/276 = 0.282609 | 表 3/5 |
| M3 `(0,21)` | 108/120 = 0.900000 | 47/276 = 0.170290 | 表 4/5 |
| M3 `(0,24)` | 113/120 = 0.941667 | 78/276 = 0.282609 | 表 4/5 |

**读法**：M1 是唯一"低泄漏区间还能动"的机制（`L=0` 时的 `R_keep` 已达 0.533）；两条 dHash 机制在**任何**能提高保留率的阈值上
泄漏都 ≥ 15/276（5.4%），因为 24 张 base 位图里有大量**同版面不同图**（十字表、流程框），像素差分分不开它们。
数值全部来自表 2/5–表 4/5 的对应行。

**M3（12 个非支配点，节选）**：`(0,5)` → R 0.650000 / L 0.057971；`(0,21)` → R 0.900000 / L 0.170290；`(0,24)` → R 0.941667 / L 0.282609（表 4/5 `M3` 段）。

**"把 R_keep 从 0.583 提到 0.90 的最小泄漏代价"**（锚 `raisingTarget`，打印在表 5/5 的 `C5` 行上方）：

| 机制 | 达标点 | `R_keep` | `L` |

即：**想保住 90% 的同源变体，最便宜的路是把 floor 一路降到 0.90，代价是负样本泄漏从 1.09% 涨到 3.26%（+2.17pp，绝对值 9 对）**。
这条路的代价不是"贵"，而是**越过 C2 门槛 1.63 倍**，属于"用误召回换召回"，不满足本卡预注册的验收线。

## 4. C1–C6 逐判据照判（表 5/5 + 锚 `criteria`）

| 判据 | 门槛 | 实测 | 结论 |
| --- | --- | --- | --- |
| **C1** 同源保留率 | ≥ 0.90 | 基线 0.583333；三机制最高 0.941667（M1 `floor=0.90`） | 满足（最佳点达标） |
| **C2** 负样本泄漏率 | ≤ 0.02 | 基线 0.010870；所有 `R>=0.90` 点的最小 L = 0.032609 | **不满足**（无达标点） |
| **C3** 逐 kind 单调 | crop-12 ≤ crop-04 ≤ scale-070 ≤ scale-085，jpeg 可与 scale-085 互换 | 基线**不满足**（scale-070 22 > scale-085 21）；`floor=0.9935` 亦不满足（jpeg-q80 17 < scale-070/085 21）；`floor=0.90` 成立（24/24/24/24/17） | 逐点记录，M1 全网格里既有成立点也有不成立点（锚 `outcome.satisfiesC3`） |
| **C4** 外呼次数 | = 0 | `externalCalls=0`（锚字段 + `selfChecks.externalCalls`） | 满足 |
| **C5** 决策 | ∈ {GO, NO-GO, UNDECIDABLE-BY-DATA} | **UNDECIDABLE-BY-DATA** | 命中第 ③ 支（关节不可达、两侧可达） |
| **C6** 全网格披露 | 200 / 25 / 全组合 | 200 / 25 / 325，逐点入锚 | 满足 |

C3 细则（表 2/5 两行对照，两种性质，禁止合并成一句）：
- **基线违反**：`scale-070(22)` 与 `scale-085(21)` 相差 1 对，是两个无损缩放之间的边界噪声，与 jpeg 无关（锚 `baseline.outcome.satisfiesC3=false`）。
- **`floor=0.9935` 违反**：逐 kind 为 jpeg-q80=17、scale-085=21、scale-070=21、crop-04=5、crop-12=0，`jpeg-q80(17)` 排在 scale 系之后，是有损重编码的变换语义差异（对齐 v2 文档 §9 已记录的 jpeg/scale 反序）。
- **`floor=0.90` 成立**：逐 kind 24/24/24/24/17。

边界声明：C3 只用于候选机制判据，不改变第 ③ 支结论（两侧各自可达但关节不可达，见锚 `verdictReason`）。

## 5. 结论与后续卡边界

**决策：UNDECIDABLE-BY-DATA（C5 第 ③ 支）—— 关节不可达、两侧可达；不换机制、不调门槛，本卡不结案。**

1. **本卡不实施任何改动**：`ImageSimilarityGate` 五常量零 diff（阈值 0.9944 / floor 0.9887 / 权重 0.75·0.6·0.5 原样），
   锚内 `productionConstants` 回显由守卫测试逐值比对。
2. **量化前沿（锚 `pareto.M1`，7 行，数字逐字抄锚）**：

   | `floor` | `R_keep` | `L` |
   | --- | --- | --- |
   | 0.9890 | 0.575000 | 0.003623 |
   | 0.9815 | 0.666667 | 0.014493 |
   | 0.9800 | 0.675000 | 0.018116 |
   | 0.9785 | 0.691667 | 0.021739 |
   | 0.9740 | 0.716667 | 0.025362 |
   | 0.9655 | 0.775000 | 0.028986 |
   | 0.9000 | 0.941667 | 0.032609 |

   读法：**C2≤2% 上限内**保留率上限 = **67.5%**（`floor=0.98`，L=1.81%，较基线 58.3% **+9.2pp**）；要摸到 **C1≥90%**
   必须把泄漏放宽到 **3.26%**（`floor=0.90`，R=94.2%，= 门槛的 1.63 倍）。两条边不可同时成立 ⇒
   需"流失-泄漏"交换率与泄漏真实伤害（查询-相关性真值）才能定夺。
3. **定夺所需数据**（不是"再扫一遍网格"）：
   (a) **交换率与伤害同秤**——41.7% 的同源流失 vs 3.26% 的负样本泄漏，需查询-相关性真值与业务对误召回的处置成本；
   (b) **带真实业务判定的负样本**——本卡语的负样本是"同出版物/跨出版物的不同图"，一旦引入"同版面不同数据"的业务口径，
   当前 0.9887 的 floor 是否过低才有结论；
   (c) **crop-12 这一档的语义裁决**——它到底算"同一张图的可识别版本"还是"另一张图"（本卡按前者计入 `R_keep`，这是 41.7% 的来源）；
   (d) **换 embedding 底座**（多模态模型换代）才算"新的可测机制"，但那是换底座不是调参数，需另立卡且必须真外呼预算。
4. **后续卡档位**：若要走 (d)，档位至少 B（真外呼 + 成本帽）；(a)(b)(c) 是口径决策，档位 A（改冻结语义）。

## 6. 数据质量与未覆盖类

- **语料可复现（自证①）**：144 个 `same-image` 对在本卡重算下 dHash 距离**全为 0**、余弦回读**全为 1**（锚 `selfChecks.sameImageDistanceZero/CosineOne` = 144/144）。
  这是"重生成语料 ≠ 当初真跑语料"的排除证据：`NearDuplicateCorpus.generate()` 的 base/变体与 v2 锚逐键对齐（`requireAligned` fail-fast 覆盖 146 个键）。
- **零外呼**：余弦取自已提交 v2 锚（历史真跑产物），本卡**不调用**任何模型接口；`externalCalls=0` 由锚字段与守卫测试双证。
- **未覆盖类**：**同页重复扫描**（同一张纸扫两次）无法在无扫描仪条件下合成，语料不含该档；
  **纯色/极低信息图**（唯一色数 ≤ 1）在 corpus 生成期即被剔除并登记（本次 0 例）。
- **锚身份**：v2 锚 SHA-256 = `82d24204fba8029673d18ea5685964cf4134d2c43e3da5746986881bf35bdc65`（锚 `corpus.anchorSha256`，守卫测试校验长度 64）。
