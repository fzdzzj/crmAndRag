> **落盘物**：本文件为 `image-near-duplicate-band-weight` 卡的定标复核记录。
> **数据源**：`docs/rag-quality/image-threshold-calibration-v1.json`（`IMAGE-THRESHOLD-CALIBRATION-1.0`，
> 2026-10-22 真跑，`RAG_VISION_EMBED_REAL=1` + `DASHSCOPE_API_KEY`）的 `pairs`，共 **90 对**余弦；
> 本文全部数字由该 JSON 重算，未二次加工。
> **实现侧对照**：`ImageSimilarityGate`（`bandOf` / `lowBandUpperBound` / `highBandLowerBound` /
> `weightOfBand`）。
> **边界**：只做只读复核。不改锚、不改阈值键与默认值、不改 `image-baseline-v1` / `pdf-ingest-image-baseline-v1` /
> `production-gray-cost-v1`，程序化套件 `ImageCrossModalSuite` 的 0.90 原样未动。

## 1. 复核口径

近似同图档的余弦区间是 `[floor, threshold)`，`floor = effectiveFloor(threshold) = min(0.9887, threshold)`。
该区间按 1/3、2/3 **现算**切三段（边界值归上一档，`>=`）：

```text
threshold   = 0.9944（默认展示口径；锚原值 0.9943679700394117）
floor       = 0.9887
Δ           = threshold - floor = 0.0057
边界 b1     = floor + Δ/3 = 0.9906      （低/中边界）
边界 b2     = floor + 2Δ/3 = 0.9925     （中/高边界）
```

- `[threshold, 1]` → `SAME_IMAGE`（不降权）
- `[b2, threshold)` → `NEAR_HIGH` → ×0.75
- `[b1, b2)` → `NEAR_MID` → ×0.6
- `[floor, b1)` → `NEAR_LOW` → ×0.5（= 旧统一系数）
- `< floor` → `CROSS_IMAGE`（过滤，不变）

> 阈值取 0.9944 还是锚原值 0.9943679700394117 对落带**没有影响**：两者算出的边界相差约 `1.1e-5`，
> 而唯一落带样本（0.9887359）低于两个 b1（0.9906 / 0.99059）。权重取值不影响落带，本节只关心落带。

## 6. 结论：当前三档是否合理

1. **与锚不冲突，且不放松。** 唯一落带样本落 `NEAR_LOW`、权重 0.5 = 旧行为；18 对同图不降权；71 对异图照旧过滤。
   换言之，本次分档改动对这 90 对定标数据的**行为变化为零**——它只在生产近重复图上体现收益。
2. **`NEAR_HIGH` / `NEAR_MID` 在本锚上零样本。** 0.75 / 0.6 属于"结构上单调、方向正确的缺省值"，**未经本锚校准**；
   不能拿本文件声称中高档权重已定标。本锚能证明的只有：最低档 0.5 与锚相容、单调关系可安全落地。
3. **结构合理。** 段边界由 `[floor, threshold]` 推导，锚重标定即自动缩放，没有第二处需要手工同步的常量；权重严格单调
   （0.5 < 0.6 < 0.75 < 1.0）、最低档不高于旧值，方向是"越接近阈值降权越轻"。
4. **数据覆盖边界。** 本锚是 **9+9 张图两两组合**（90 对），不是"查询图 → 库内候选图"的生产分布。真正的近重复对
   （同图不同版本、同版式页）只在生产灰度查询里出现——要校准中高档，必须采生产数据。

## 7. 如需调整的具体建议

- **先采样再生产**：从生产灰度真跑记录里抽 query-image 对的余弦，按 §1 同一分带统计；每带样本 ≥ 30 再谈调权重。
- **`NEAR_HIGH`**：若采样显示该带内多数人判为"同一张图的不同版本"，可上调到 0.8~0.9（仍 < 1.0）；若多数是异图，
  保持 0.75 或下调（不得低于 0.5）。
- **`NEAR_MID`**：零样本时不建议先动 0.6；它与相邻档的差距（0.15）已足够表达单调性。
- **`NEAR_LOW` 不动**：上抬 0.5 等于放宽近似图的排序（误召回风险），下压等于加重视觉近同图的误杀风险。
- **锚重标定后**：段边界自动跟随，无需改代码；但三档权重常量要按 `docs/dynamic-config-keys.md` 该键的"权重常量需人工复核"
  注记重新评估。若真实语料间隔带变宽（更可分），可再评估是否仍按三等分（换分法只动 `bandOf` 的推导，不改配置键）。

## 8. 复算与限制

- **复算方法**：读 JSON 的 `pairs`，按 `cosine` 分桶（`SAME >= 0.9944`、`b2..threshold`、`b1..b2`、`floor..b1`、
  `< floor`）。本次统计用 PowerShell 以 UTF-8 读入后 `ConvertFrom-Json` + `Group-Object` 完成，未落临时脚本、未改任何文件。
- **限制一**：90 = 18 `same-image` + 18 `same-class` + 54 `cross-class`；图对是对称去重后的组合，不是查询-候选对。
- **限制二**：`NEAR_HIGH` / `NEAR_MID` 零样本、`NEAR_LOW` 单样本，所有分位与占比仅作存档，不足以支持权重取值的统计检验。
- **限制三**：本文件的统计口径是默认阈值 0.9944；运营改键后边界随之平移，需按新阈值重算（代码里 `bandOf` 已自动处理，
  本文数字不再适用）。
