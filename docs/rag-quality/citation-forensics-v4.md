## 0. 结论（TL;DR）

1. **A 类（噪声误引，引用块不支撑答案）本轮 0 例**。19 个 citP<1 案例中，每一个非黄金引用块的 excerpt 都**字面承载**了答案所引内容——模型没有引用检索噪声。逐例 excerpt 原文见 §3。
2. 短板主因是 **B 类（口径特性）18 例**，可再分三个子型：**B1 切分边界内容重复/跨块段落** 9 例（被引句是黄金块尾部在邻块头部的重叠复本，或一个段落被切到两块）、**B2 黄金标注口径缺口** 8 例（问"各区域"只标 2 区、筛选/比较需引排除项、XR-500 年度 16 人时确超阈值却未标等）、**B3 黄金标记跨块撕裂** 1 例（T-15，fixture 标记 `【GOLD:customer-onboard-3】` 被切分边界撕裂，黄金归点与内容主体分离）。
3. **C 类（recall 连带）1 例**：T-14，黄金块 `customer-sop-3` 三轮（v2/v3/v4）稳定未召回（recall=0.5），模型被迫以边界重叠邻块组装答案 → 归并 T-14 拆路残留问题，本卡不另开。
4. **对齐器行为是 citP 的双向噪声源**（4 例观测）：TB-10 把黄金引用 [1] 重映射到非黄金块（直接丢分）、T-15 丢弃黄金引用 [1]、I-03 丢弃合法邻块引用后 citP 复原 1.0、M-04 把 ZB-220 引用重映射到不承载该内容的块（反而抬分）。**"生成侧引用精化"若立项，第一抓手应是对齐器重映射正确性（重映射目标块必须字面承载被引句），而非模型。**
5. T-15 citP `0.333(v2) → 0(v3) → 0(v4)` 的波动形态 = 引用集合 LLM 非确定性漂移 × 恒定黄金锚错位的合成（§6）。

## 2. 判读口径

- citP 公式（i05-forensics 在案口径）：引用编号 n → `retrieved[n-1] ∈ goldenIds` 的占比；分母 = 对齐后答案的引用编号集合（`citationsAfter`，去重）。
- 三分类：**A 噪声误引**（非黄金引用块的 excerpt 不支撑其声称的答案内容）；**B 口径特性**（非黄金块字面支撑答案，失分源于黄金标注/切分/语料承载口径）；**C recall 连带**（黄金未全召回迫使模型以邻块作答）。
- 证据纪律：非黄金引用块 excerpt 一律原样粘贴（400 字窗口，trace 原文），判读只陈述 excerpt 内可验证的字面对应；excerpt 窗口截断处明确标注"（excerpt 400 字窗口止于此）"。

## 5. 机制发现

- **M1 切分边界内容重复**（9 例直接成因）：语料分块的 overlap 让黄金块尾句在邻块头部重复出现，被引句在两块中均字面可查；模型引了邻块（次序/位置更近或更靠后）即计非黄金。典型字面证据：T-05 邻块 excerpt 以"程中要保持…"开头（"过"字在黄金块截断处）、M-02 以"口是否充足…"开头。**这是 citP 短板最大的单一机制**。
- **M2 黄金标注口径缺口**（8 例）：问域（TB-01"各区域"）、论证结构（TB-08/TB-10 排除论证、TB-11 比较列举）、标注漏项（TB-10 XR-500 年度 16 人时确超阈值未标）、跨题归属（M-01 引用了 M-03 的黄金块）——黄金集与"回答该问题所需引用集"不对齐。
- **M3 黄金标记跨块撕裂**（T-15）：fixture 标记 `【GOLD:customer-onboard-3】` 位于段落首，切分边界落入标记文本（customer-sop-3 excerpt 以残片 `customer-onboard-3】` 开头），数据准备器按标记起点归块 → 黄金=customer-sop-2（仅含段首句），内容主体在 customer-sop-3。**无论模型引用哪块，黄金口径下必错一块**。
- **M4 对齐器重映射/丢弃双向噪声**（4 例观测）：重映射目标块不校验"字面承载被引句"（TB-10、M-04），黄金引用可被丢弃（T-15、I-03）。citP 因此在 0.25↔1.0 区间内受对齐器行为摆布，与模型引用质量解耦。

## 7. 三分支定向建议

- **分支 A（噪声误引）→ 不立项**：本轮 0 例，"生成侧引用精化（模型误引噪声块）"缺乏数据支撑。若后续仍要开生成侧引用卡，**第一抓手应改为对齐器重映射正确性**（M4：重映射目标块必须字面承载被引句 + 黄金引用不得无故丢弃）——TB-10/T-15 的丢分与 M-04 的错向抬分都是可直接红绿的缺陷面，属生成/对齐链路而非模型。
- **分支 B（口径特性）→ 主流，三分路处置**：
  - B1（边界重复，9 例）：属检索链路契约面（切分 overlap 语义与 citP 判卷口径）。两个候选方向——判卷口径把"重叠区句子"按多块承载计分，或切分链路做重叠区归属标注——均为契约改动，须走受控解冻（`contracts-frozen.md`），另卡立项；本卡不改。
  - B2（标注缺口，8 例）：改黄金=改 case=升 SUITE_VERSION（套件 javadoc 在案语义）。TB-01（"各区域"只标 2 区）、TB-10（XR-500 年度漏标）是最明确的漏项候选；按卡边界"不动 case"，本卡只登记不改，建议并入下一版套件受控校准。
  - B3（标记撕裂，T-15）：`RagBenchmarkDataPreparer` 加固候选——标记完整性校验（禁止标记被切分边界撕裂时静默归块）或按"内容主体块"归点。零行为风险，可作独立小卡。
- **分支 C（recall 连带）→ 归并既有问题**：T-14 黄金 customer-sop-3 三轮稳定未召回（recall=0.5），归并 T-14 拆路残留问题，本卡不另开。
