# 近重复相关性盲标表 · v1（30 行）

本表 6 条查询 × 每条现行前 5 个候选 = 30 行。请只依据「查询原文」与「候选文本」判断两件事，大约 15 分钟。

## 一、`relevance`：这条候选有多相关（只填 0 / 1 / 2）

| 取值 | 含义 |
| --- | --- |
| `2` | 直接回答了这条查询 |
| `1` | 同主题，有参考价值但不直接回答 |
| `0` | 与这条查询无关 |

## 二、`isNearDuplicate`：是不是同一张图的不同版本（只填 Y / N / U）

判断对象是「同一查询里、名次比本行更高的候选」。

| 取值 | 含义 |
| --- | --- |
| `Y` | 与更高名次的某张图是同一张图的不同版本 |
| `N` | 不是 |
| `U` | 看不出来（信息不足就填 `U`，这是合法答案，不算错） |

## 三、另外两列

- `annotator`：填你的署名。请不要写 agent / assistant / ai / model 之类字样。
- `annotatedOn`：填表日期，格式 `YYYY-MM-DD`。

## 四、三条纪律

1. **不要参考任何锚或分数**：本表故意不提供相似度、档位、机器名次提示。
2. **不要改结构**：不要改 `rowId`、不要调整行序、不要增删行。
3. **拿不准就填 `U`**：不要为了填满而猜。

## 五、填写方式

- 用 Excel / 文本编辑器直接打开 CSV；CSV 为 UTF-8（无 BOM），Excel 请用「数据 → 自文本」按 UTF-8 导入。
- 候选文本里的 `\n` 是原文换行的显示形式（一行一条记录），不是内容错误。
- 只填 `relevance` / `isNearDuplicate` / `annotator` / `annotatedOn` 四列，其余列保持原样。
- 填完保存后，由执行者跑打分器读取本表。
