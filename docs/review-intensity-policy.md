# 复核强度分级校准政策（review-intensity-policy）

> 状态：本卡（calibrate-review-intensity）为首个 **C 档试点**，随本卡合入生效。
> 本文件是复核强度的人为工作流约定；它**不替代、不放松任何门禁**（三段 CI、PMD/SpotBugs 台账、权限覆盖、schema 漂移、回归基线等自动门禁全部原样保留）。

## 一、宗旨与边界

- 本政策只调**人工复核强度**，白纸黑字写在自动化门禁之外的部分。
- 自动门禁本身不冗余、不削减：任何档位的卡都仍以门禁实测输出为最终证据。
- 档位判据按**变更内容**判定，卡在 proposal 头部自 declare；判错档位按偏差对待，由指导侧在核验时纠正。

## 二、三档判据（D1）

按卡片变更内容判档，`A > B > C` 优先级取最高。

| 档位 | 判据（含任一即升档） |
| --- | --- |
| **A 档** | 含任一：DB 迁移脚本、权限语义变更、真跑（`RAG_BENCHMARK_REAL=1`）、冻结契约改动、合并 / push 本身 |
| **B 档** | 常规产品代码 + 测试，且不含 A 档要素 |
| **C 档** | 纯文档、openspec 归档批、logbook、非门禁脚本 |

注：按 diff 行数分档不可行——行数与风险不同构（一行迁移脚本 ＞ 五百行文档）。

## 三、职责矩阵（A / B / C × 执行自跑 / 指导抽查 / 复核动作）

| 变更档位 | 执行自跑（不变） | 指导抽查（不变） | 复核动作 |
| --- | --- | --- | --- |
| **A 档** | 全量门禁 + 证据留痕 | 全量逐格核验 | 复核 agent 全量：门禁复跑、哈希留痕真实性、双树核对、证据审计 |
| **B 档** | 全量门禁 + 证据留痕 | 全量逐格核验 | 复核 agent 减配：证据审计（命令 + 哈希留痕真实性核验）+ surefire 定向复跑 + 机械脚本双树核对；Docker IT / 真跑不再复跑，合并后 CI 兜底 |
| **C 档** | 全量门禁 + 证据留痕 | 单遍逐格核验 + 机械脚本出表 | **不派复核 agent**（指导 agent 单遍核验 + `scripts/tests/review-mechanical-check.sh` 出表替代） |

## 四、勾选哈希留痕规则（不豁免）

- 所有档位**一律不豁免**勾选哈希留痕规则：tasks 勾选行下一行须附 6 空格缩进留痕——「补勾依据」+ 可独立复跑的命令与哈希（合并节点双亲、分支在册、提交 stat、CI 轮次等）；禁止无证据补勾、禁止以代码推导或记忆冒充实测。
- 规则原文见 `openspec/changes/archive/close-openspec-task-residue/specs/openspec-task-residue/spec-delta.md`（THEN：勾选行下一行 6 空格留痕）。

## 五、机械核对脚本

- `scripts/tests/review-mechanical-check.sh`：两树 git 状态 / HEAD 位置、分支 vs master diff 文件清单、指定卡 tasks.md 未勾项计数、基线文件 vs master 漂移。
- 该脚本**恒 exit 0，只报告不判定**；不接 CI、不接 `merge-gate.sh`（D4 边界）。

## 六、生效语义

- **合入后**启动的新卡：按本政策档位走。
- **在途卡**（本卡合入前已在执行的卡）：按旧规则，不追溯回溯。
- 本卡自身按 **C 档试点**执行：指导侧单遍核验 + 机械脚本出表，不派复核 agent。
